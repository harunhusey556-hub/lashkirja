# P5 accessibility pass (2026-10-06)

Branch `feature/p5-a11y`. Scope: `ios-native/App/Sources` except `Chat/`. No visual backgrounds were added to icon-only buttons (owner decision "A", 2026-10-01). Swift cannot be built on Windows, so the `iOS native` CI run is the only compile check; nothing was run in a simulator.

## Shared helpers (`Components/Components.swift`)

| Helper | Purpose |
| --- | --- |
| `withMotion` / `.motion(_:value:)` | `withAnimation` / `.animation` that are skipped when Reduce Motion is on |
| `.scaledFont(size:weight:design:relativeTo:)` | fixed point sizes that still follow Dynamic Type (`@ScaledMetric`) |
| `.tapTarget()` | 44pt minimum hit area via `frame` + `contentShape`, no background |
| `.lineLimitUnlessLarge()` | one line normally, wraps at accessibility sizes |
| `.moneyHero()` | headline money: one line, `minimumScaleFactor(0.5)` as last resort |

No pure logic was added, so there is no new LashKirjaCore code or test.

## Performance

Looked for per-render formatters, unkeyed `ForEach`, main-thread image decoding and heavy work in `body`. Nothing clear turned up: `ForEach` over model data is keyed by `id`, thumbnails and bank logos use `NSCache` with `byPreparingForDisplay`, and no formatter is created per render. No performance changes made. Not measured with Instruments.

## Not done / follow-ups

- Contrast was not audited.
- Fixed 28/34/36pt icon badge frames were left unscaled; the glyphs are decorative.
- Input errors are exposed accessibly in a few forms only; a full pass is a follow-up.
